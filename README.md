# The Gang - Version Ultime Officielle

Toutes les améliorations majeures demandées sont intégrées :
- **Sélection du mode de jeu** : Classic, Pro, Gangster (avec explications des règles et seuil d'alarme ajusté).
- **Abattage contrôlé par l'Hôte** : Révélation manuelle pas-à-pas avec détection immédiate des anomalies.
- **Cartes Complice (Bonus) & Effraction (Malus)** : Système de vote unanime pour l'utilisation, et vote spécifique pour la carte **Gros Bras** (majorité + vote double de l'hôte en cas d'égalité).
- **Volet Poker officiel** : Schéma graphique avec mini-cartes correspondant exactement à la carte physique du jeu.
