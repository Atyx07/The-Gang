# The Gang - Version Officielle Complète

Conforme à 100% aux règles officielles (IELLO / KOSMOS) :
- **3 Cartes Coffre-fort & 3 Cartes Alarme** avec bascule visuelle fidèle (fermé/ouvert et éteint/sirène).
- **Règle officielle de l'Alarme** : 1 seule alarme max activée par braquage échoué quel que soit le nombre d'anomalies.
- **Victoire / Défaite** : Déclenchée dès 3 coffres ou 3 alarmes.
- **Cartes Malus (Effraction) & Bonus (Complice)** : Déclenchées après chaque braquage réussi ou raté.
- **Abattage dans l'ordre croissant** : Révélation du jeton 1 au jeton N avec gestion officielle des égalités strictes (Splits).
