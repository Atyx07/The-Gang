# The Gang - Version Ultime v4.1

Corrections et améliorations intégrées :
1. **Abattage dans l'ordre décroissant** : Débute par le gangster ayant le jeton avec le plus d'étoiles vers celui avec le moins d'étoiles.
2. **Conductrice corrigée** : Annonce strictement le type générique de sa main (ex: « J'ai une paire », « J'ai un brelan ») sans aucune précision de valeur ou de roi/dame.
3. **Affichage du prochain Bonus/Malus** : Directement visible et mis en valeur dans l'encadré de résultat dès que l'hôte valide le verdict du braquage.
